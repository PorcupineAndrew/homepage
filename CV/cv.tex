\section{Research Experience}

\cvitem[\parskip]{\textbf{Network \& Information Security Lab, Tsinghua University}}{Sep. 2020 -- Aug. 2026}

Student Researcher, co-advised by \href{https://www.internethalloffame.org/inductee/jianping-wu/}{Prof. Jianping Wu} and \href{https://sites.google.com/site/qili2012/}{Prof. Qi Li}.

\textbf{Research keywords:} Internet routing security, AI for security, network measurement, anomaly detection, traffic analysis
\begin{itemize}
    \item Led the development and deployment of a BGP routing anomaly detection system at China Telecom, based on a novel network representation learning model that captures intrinsic AS routing policies in a semantics-rich vector space.
    \item Led the first systematic study of the emerging stealthy BGP hijacking threat under partial ROV deployment, establishing an online monitoring service, the first real-world incident dataset, and a comprehensive risk assessment framework.
    \item Leading an ongoing study to build an AI agent framework that reasons over open-source intelligence to uncover hidden relationships when domain-specific data falls short, and to distinguish malicious attacks of interest from benign events.
    \item Leading an ongoing study to uncover adversarial manipulation risks in common AS relationship inference pipelines, demonstrating a practical attack that can manipulate ASRank results by injecting carefully crafted BGP routes.
    \item Developed a lightweight consensus framework tailored for decentralized network-layer security, and developed an encrypted malicious traffic detection framework dedicated to handle low-quality, insufficient training data.
\end{itemize}
\addvspace{.8em}

\cvitem[\parskip]{\textbf{NetMan Lab, Tsinghua University}}{Sep. 2018 -- Aug. 2020}
Student Research Intern, advised by \href{https://netman.aiops.org/~peidan/}{Prof. Dan Pei}.

\textbf{Research keywords:} AI for operations, root cause localization, anomaly detection, log analysis
\begin{itemize}
    \item Designed and evaluated a generalized root cause localization approach for multi-dimensional data from online services, achieving over 30\% F1-score improvements and identification of external faults.
    \item Developed and evaluated a semantics-aware unsupervised log anomaly detection framework that enables joint detection of sequential and quantitative anomalies, and developed an adaptive log parsing system tailored for log compression.
\end{itemize}
